# 分支：feat/single-container-image

- 新增 `Dockerfile.all-in-one`，支持把前端、Flask API 和 MySQL 打包到一个镜像里。
- 新增单容器启动、停止和冒烟测试脚本：`docker-single-up.sh`、`docker-single-down.sh`、`docker-single-smoke.sh`。
- 新增 GitHub Actions 发布流程，推送后可发布到 `ghcr.io/yang-sd/resource-planning-gantt-chart`。
- 部署文档补充“拉镜像直接运行”和“源码构建单容器”两种极速部署路径。

# 版本迭代记录

## v1.11.0

- 新增移动端响应式适配，手机访问时左侧导航压缩为顶部横向入口。
- 总览项目清单在小屏下改为卡片式信息结构。
- 资源排期时间轴在手机上支持横向平滑滚动，避免 14 天或一个月视图被硬挤到一屏。
- 组织管理、记录中心和弹窗在移动端调整为更适合触控的卡片、横向列表和底部弹层。

## v1.10.3

- 登录页移除默认账号密码展示，账号和密码输入框默认置空。
- 登录态改为后端 HttpOnly Cookie，前端不再持久化 script-readable token。
- 后端新增登录失败限流、CSP、HSTS、X-Frame-Options、nosniff 等安全响应头。
- 管理员初始密码改为环境变量控制，并新增 `backend.manage set-password` 改密命令。

## v1.10.2

- 记录中心删除归档详情改为按成员分组展示对应负责项目。
- 归档项目补充日期、优先级和状态，方便回溯删除前的人力分工关系。

## v1.10.1

- 删除项目组时新增二次确认，明确提示是否同步删除组内成员和项目。
- 确认删除后先归档团队、成员和项目核心字段，再从主数据中移除。
- 记录中心新增“历史删除组人项目”视图，用于回溯级联删除内容。

## v1.10.0

- 修复资源排期中同一成员非重叠项目仍被强制堆叠的问题。
- 修复节假日斜纹铺满空白时间轴的问题。
- 新增 NAS 轻量部署模式和 PostgreSQL 公共数据库适配。
- 新增 PostgreSQL 表和字段中文注释，数据库工具可直接查看数据字典。

## v1.9.0

- 组织管理的团队项目和成员负责项目卡片新增“转交”按钮。
- 项目转交弹窗支持选择新负责人，并自动同步项目所属团队。
- 转交保存后写入操作记录，并将组织管理详情切换到新负责人。
- 补齐项目 README、部署文档、架构文档、测试文档和脚本注释。

## v1.8.0

- 新增个人资料头像上传，支持 PNG/JPG/WebP/GIF，最大 10MB。
- 上传头像存储到 MySQL，并通过独立头像接口加载，避免首屏 JSON 过大。
- 修改密码不再要求填写当前密码，只需要新密码和确认新密码。
- 账号卡片和成员头像支持图片头像与文字头像 fallback。

## v1.7.1

- 新建成员时自动创建登录账号，初始密码统一为 `123456`。
- 当前账号卡片支持打开个人资料弹窗。
- 个人资料保存会同步成员档案、团队负责人名称和操作记录。
